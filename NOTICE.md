# Public Repository Notice

Dormify was developed as an academic software engineering project for a real
university-housing use case.

This public repository is a sanitized portfolio version. It intentionally does
not include:

- real student or resident records;
- operational housing inventory exports;
- production credentials or environment files;
- internal deployment endpoints or infrastructure secrets;
- institution-owned logos or maps;
- confidential operational correspondence or incident details.

Names, example accounts, sample values, and some technical descriptions may be
generalized or replaced with synthetic equivalents.

The repository should not be interpreted as an official institutional release,
production deployment package, or statement of current institutional policy.

See `LICENSE` for source-code usage restrictions.
